# marrow-core

Turns pose landmarks (a webcam or a recorded clip) into typed events, driven by a JSON movement spec. Plain TypeScript, no UI framework. Everything runs on-device.

```
PoseSource -> LandmarkSmoother -> Engine(spec) -> events
```

Apps import only from the package entry (`marrow-core`). Example data is available at `marrow-core/specs/*` and `marrow-core/fixtures/*`.

## Quick start

```ts
import { createFixturePlayer, createPipeline, parseFixture, parseMovementSpec } from 'marrow-core';
import specJson from 'marrow-core/specs/elbow-cycle.json';
import clipJson from 'marrow-core/fixtures/elbow-cycle-3reps.json';

const parsed = parseMovementSpec(specJson);
if (!parsed.ok) throw new Error(parsed.issues.map((i) => `${i.path}: ${i.message}`).join('\n'));

const pipeline = createPipeline({
  source: createFixturePlayer(parseFixture(clipJson), { loop: true }),
  spec: parsed.spec,
});
pipeline.on('rep', (e) => console.log('rep', e.count));
pipeline.on('form:warning', (e) => console.log(e.message));
pipeline.onFrame(({ frame, metrics, phase }) => {
  /* draw the overlay */
});
await pipeline.start();
```

## Public API

### Types and landmarks

- `Frame` is `{ t: number; landmarks: Landmark[] }`, with `t` in milliseconds and 33 landmarks.
- `Landmark` is `{ x, y, z, visibility }`. `x` and `y` are in [0, 1] image space.
- `LM` maps names to MediaPipe indices (`LM.leftKnee === 25`). `LANDMARK_NAMES` lists them in index order.

### Geometry

- `angleAt(a, b, c, plane?)` is the angle at `b` in degrees, in [0, 180], or `NaN` for a zero-length segment. `plane` is `'xy'` or `'xyz'` (default).
- `distance(a, b)` and `bodyScale(frame)` (mid-shoulder to mid-hip length).

### Smoothing

- `OneEuroFilter({ minCutoff, beta, dCutoff })` with `filter(value, tMs)` and `reset()`.
- `LandmarkSmoother(opts)` with `smooth(frame)` and `reset()`. It keeps `t` and `visibility`.

### Movement spec

- `parseMovementSpec(json)` returns `{ ok: true, spec }` or `{ ok: false, issues: { path, message }[] }`. It never throws.
- `MovementSpecSchema` is the zod schema. `MovementSpec` is the type.
- The format is described in the feature design (`.kiro/specs/marrow-core/design.md`, "Movement spec format").

### Engine

- `createEngine(spec)` returns `{ push(frame), advance(t), reset(), repCount, phase }`.
- `push(frame)` returns the events that frame produced.
- `advance(t)` accounts for time passing without a frame. It ends an active hold with reason `lost-pose` once `t` is more than `holdGapMs` past the last valid frame, and does nothing else. Pass it the timestamp from `onPoseLost`.
- The engine reads no clock. Output depends only on the spec and the ordered `push` and `advance` calls since `reset()`.
- `evaluateMetrics(spec, frame)` returns the metric values for a frame (`NaN` when a landmark is below `minVisibility`).

### Events

| `type` | Fields |
| --- | --- |
| `phase` | `t`, `from` (string or null), `to` |
| `rep` | `t`, `count`, `durationMs`, `phaseEntries` |
| `hold:start` | `t` (when the condition began), `holdId` |
| `hold:tick` | `t`, `holdId`, `elapsedMs` |
| `hold:end` | `t`, `holdId`, `durationMs`, `reason` (`released` or `lost-pose`) |
| `form:warning` | `t`, `ruleId`, `message`, `value` |
| `rom:sample` | `t`, `metric`, `min`, `max`, `trigger` |

A `rom:sample` is skipped when no valid value was observed since the previous trigger.

### Sources

- `PoseSource` has `start()`, `stop()`, `onFrame(fn)`, `onPoseLost(fn)` and `onError(fn)`. Each subscription returns an unsubscribe function. `onPoseLost` receives the timestamp of a video frame with no pose, and no `Frame` is delivered for it.
- `createFixturePlayer(fixture, { speed, loop, clock })` plays a fixture. Frames keep their recorded `t`, offset on each loop so `t` keeps increasing. `speed` scales only the schedule. Pass a `Clock` (`setTimeout` and `clearTimeout`) to run it without real timers. The player never calls `onPoseLost` listeners.
- `replay(fixture)` yields the frames synchronously, for tests and offline analysis.
- `parseFixture(json)` validates a fixture and throws `FixtureError` (with `field` and `frameIndex`) on a bad one.

### Pipeline

- `createPipeline({ source, spec, smoothing })`. `smoothing` is `OneEuroOptions`, or `false` to pass landmarks through. Omitted means smoothing with defaults.
- `pipeline.on(type, fn)` registers a typed event listener and returns an unsubscribe function.
- `pipeline.onFrame(fn)` receives `{ frame, metrics, phase }` for each processed (smoothed) frame.
- `pipeline.start()` and `pipeline.stop()`. `stop()` stops the source, unsubscribes from it and removes all listeners.
- When the source reports `onPoseLost(t)`, the pipeline calls `engine.advance(t)` and dispatches the resulting events.

## Fixtures

`fixtures/elbow-cycle-3reps.json` is synthetic and is generated by `scripts/make-fixture.ts`. Regenerate it with `npm run make-fixture` in this folder. A test checks that the committed file equals the script's output.
